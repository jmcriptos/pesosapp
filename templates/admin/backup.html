Backup de Base de Datos

Estado y gestion de backups de la base de datos PostgreSQL

Configuracion Actual

Para ver la fecha del ultimo backup y el total disponible, ejecuta: heroku pg:backups --app pesosapp

Backup automatico Diario a las 02:00 AM (America/Curacao)
Retencion Heroku Ultimos 5 backups (plan Mini/Basic). Complementar con exportacion externa para 7+ dias.
Exportacion externa Disponible via scripts/backup-export.sh
Backup pre-migracion Obligatorio via scripts/safe-migrate.sh

Comandos de Backup

Backup Manual Inmediato

heroku pg:backups:capture --app pesosapp

Listar Backups Disponibles

heroku pg:backups --app pesosapp

Verificar Schedule Activo

heroku pg:backups:schedules --app pesosapp

Descargar Ultimo Backup

./scripts/backup-export.sh

Migracion Segura (con backup)

./scripts/safe-migrate.sh

Restaurar desde Backup

1. Listar backups

heroku pg:backups --app pesosapp

2. Restaurar ultimo backup

heroku pg:backups:restore --app pesosapp --confirm pesosapp

3. Restaurar backup especifico (ej: b003)

heroku pg:backups:restore b003 DATABASE_URL --app pesosapp --confirm pesosapp

Atencion: La restauracion causa downtime. Planificar fuera de horario laboral. Ver documentacion completa en docs/backup-restore.md
